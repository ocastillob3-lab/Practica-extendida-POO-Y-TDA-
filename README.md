# Practica-extendida-POO-Y-TDA-

## Descripción
Este proyecto consiste en desarrollar un programa en Java para registrar empleados y calcular la nómina mensual de una empresa el programa permite ingresar empleados fijos y empleados por hora, calcular sus pagos y mostrar un reporte con el total de trabajadores y el total de la nómina.

## Tecnologías utilizadas
- Java
- Eclipse IDE
- Programación Orientada a Objetos (POO)

## Estructura del proyecto
- `Empleado.java`: contiene la clase abstracta y los datos generales de los empleados.
- `EmpleadoFijo.java`: realiza el cálculo del sueldo mensual más la bonificación.
- `EmpleadoPorHora.java`: calcula el pago según las horas trabajadas.
- `Main.java`: contiene el menú principal, el registro de empleados y la impresión de la nómina.
- `Explicacion.txt`: contiene la explicación de los conceptos utilizados en el programa.

## Funciones del programa
- Seleccionar el mes de la nómina.
- Registrar empleados fijos y empleados por hora.
- Calcular el pago de cada empleado.
- Mostrar la información de los empleados registrados.
- Calcular el total de trabajadores y el total de la nómina.
- Validar los datos ingresados.

## Conceptos aplicados
En este proyecto utilicé clases, objetos, constructores, encapsulamiento, abstracción, herencia y polimorfismo también utilicé un arreglo `String[]` para almacenar los meses del año y un `ArrayList` para guardar los empleados registrados.

## Ejemplo de resultado
Al registrar dos empleados con los datos solicitados en la práctica, el programa debe mostrar un total de 2 trabajadores y una nómina de Q 7,300.00.

## Ejecución
El proyecto se puede abrir desde Eclipse IDE para ejecutarlo, se debe abrir el archivo `Main.java` y seleccionar **Run As → Java Application**.

## Conclusión
Con esta práctica aprendí a utilizar la programación orientada a objetos en Java, organizar un programa en diferentes clases y trabajar con arreglos y listas para registrar información y realizar cálculos.
